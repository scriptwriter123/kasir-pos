Penanganan Khusus PC User Luar Jaringan (Offline)

Solusi untuk kasir yang tidak memiliki koneksi internet: terbitkan lisensi langsung dari teks .posreq dan kirim via WhatsApp.
Offline Helper
📌 Alur Kerja Aktivasi PC Kasir Tanpa Internet:
  1. Di PC kasir yang tidak ada internet: User membuka aplikasi POS ➔ Tab Aktivasi Offline ➔ Klik "Simpan Permintaan (.posreq)".
  2. User mengirimkan file atau isi teks .posreq tersebut ke WhatsApp Admin.
  3. Admin menempelkan isi .posreq pada formulir di bawah ini dan klik "Terbitkan Lisensi Offline".
  4. Server akan otomatis menandatangani lisensi digital Ed25519 dan mengunduh file .poslic.
  5. Admin mengirimkan file .poslic tersebut balik ke WhatsApp User untuk diimpor ke aplikasi POS kasir!
